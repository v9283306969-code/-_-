# Проект: учёт АУСН для ИП (маркетплейсы)

Каталог ведётся для подготовки расчёта налога по АУСН и корректного заполнения операций в ЛК АУСН ФНС.
Любой агент, открывший каталог, должен сначала прочитать этот файл и `docs/03-Заполнение-операций.md`.

## Кто налогоплательщик

| Параметр | Значение |
|---|---|
| Статус | ИП, без сотрудников |
| Регион | Краснодарский край |
| Режим | АУСН, объект «Доходы – Расходы», ставка 20 % |
| Минимальный налог | 3 % от доходов (применяется, если больше налога по 20 %) |
| Начало режима | 01.02.2026 |
| Площадки | Ozon (FBO+FBS), Wildberries, заявлен Яндекс.Маркет |
| Банк | Сбер, счёт …0486 (единый для расчётов) |

Персональные данные (ИНН, адрес, ФИО) в документацию не переносим — только суммы и контрагенты.

## Правила для агента

1. `НАЛОГИ_2026.xlsx` — **историческая книга, только чтение**. Не перезаписывать.
2. ЛК АУСН, банк и маркетплейсы — **никаких изменений** без прямого указания владельца.
3. Источник истины по налогу — карточка начисления в ЛК АУСН («История начислений» → «Расчет налога»), а не наша таблица.
4. Источник истины по доходу — **банк + акт сверки площадки**, а не отчёт о реализации (см. `docs/03`).
5. Дата операции — **дата отчёта агента** (месяц взаимозачёта), а не последнее число месяца.
6. Все суммы в рублях с копейками; округление — только при сравнении.
