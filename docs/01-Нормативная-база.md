# Нормативная база: как ФНС и Ozon требуют вести АУСН с маркетплейсами

Источники ниже прочитаны вживую (через браузер), тексты приведены дословно.
Дата фиксации: 31.10.2026 – 01.11.2026.

## 1. ФНС: справка в ЛК АУСН (lk-ausn.nalog.gov.ru), вопрос «Если я работаю с маркетплейсом»

Дословно по смыслу и формулировкам:

1. Банк **автоматически размечает поступления от маркетплейса как «приход»**, если площадка перечислила всю сумму выручки.
2. Если площадка **удержала комиссию**, нужно **дополнительно внести взаимозачёт** — банк об удержании не знает.
3. При объекте **«Доходы – Расходы» обязательно вносить и доходы, и расходы**.
4. Простой случай: удержана одна сумма — она вносится **и как приход, и как расход** (одна и та же сумма).
5. Сложный случай (пример ФНС): продажи 1 000, комиссия 100, возврат покупателю 200, перевод на счёт 700 → вносится:
   - **приход 300**,
   - **возврат прихода 200**,
   - **расход 100**.
6. **Месяц взаимозачёта** определяется по дате, указанной маркетплейсом в **отчёте агента / документе о состоянии расчётов**. Пример: сделки за январь, взаимозачёты проведены 5 февраля → сведения вносятся **за февраль**.
7. Для сверки используется **Протокол информационного обмена** (сервис «Оперативный контроль») — https://ausn.nalog.gov.ru/.

Дополнительно (общие правила АУСН): налоговый период — **календарный месяц**, отчётность не сдаётся, налог считается автоматически по данным ЛК.

## 2. Ozon Банк: «Внести сумму взаимозачёта по маркетплейсу Ozon»

URL: https://help-bank.ozon.ru/business/ausn/account-ausn-fns/settlement-ozon

Ключевое:

- **Почему нужен взаимозачёт**: «Маркетплейс Ozon перечисляет на банковский счёт только часть выручки — после удержания вознаграждения и стоимости других услуг. Поэтому банк не получает информацию об общем доходе и передаёт в налоговую только сумму, которая поступила на счёт. Данные по взаимозачёту — это суммы, которые удержал маркетплейс».
- **Из каких отчётов брать**: **Акт сверки** (Финансы → Документы → Акт сверки) и, при наличии строки «Агентский отчёт», дополнительно **Отчёт о перечислениях**.
- **Правило формирования сумм**: **Приход = Расход + Возврат прихода − Возврат расхода**.
- **Строка «Требование о переводе третьему лицу»** (погашение займа Ozon Кредит из выручки) **не передаётся автоматически** и вносится **дополнительно как Приход**; возможность учесть её в расходе зависит от того, что погашается.
- **Задолженность перед Ozon** на начало или конец периода: если «Сальдо начальное» или «Сальдо конечное» по дебету > 0 — есть задолженность, взаимозачёт нужно скорректировать.
- **Как вносить**: ЛК АУСН → **Операции** → **Добавить** → **Взаимозачёт** → поля **Приход, Возврат прихода, Расход, Возврат расхода**.
- С **19.10.2026** Ozon может передавать взаимозачёты автоматически; исключение — «Требование о переводе третьему лицу».

### 2.1. Типы строк Акта сверки → тип взаимозачёта (таблица Ozon)

**Расход, знак «+»:**
Отчёт о реализации · Акт выполненных работ селлера (исходящий) · Отчёт о перевыставлении услуг (исполнении поручений) · Корректировка сумм комиссионного вознаграждения · Корректировка стоимости услуг · Акт об оказанных услугах (Звёздные товары) · Отчёт по штрафам · Корректировка сумм комиссионных товаров и сумм комиссионного вознаграждения · Акт о страховой премии · Отчёт по штрафам (бейдж «Оригинал»).

**Возврат прихода, знак «−»:**
Отчёт о реализации (отрицательные строки) · Отмена выкупа товара у селлера · Товарная декомпенсация по типам документов · Корректировка акта о компенсации на сумму оставшихся баллов · Корректировка отчёта о реализации · Корректировка суммы акта о премии.

**Возврат расхода, знак «−»:**
Корректировка сумм комиссионного вознаграждения · Корректировка стоимости услуг · Отчёт по штрафам · Отчёт о перевыставлении услуг (исполнении поручений) · Корректировка сумм комиссионных товаров и сумм комиссионного вознаграждения · Отчёт по штрафам (бейдж «Оригинал»).

**Из Отчёта о перечислениях:**

| Тип взаимозачёта | Операция | Знак |
|---|---|---|
| Расход | Удержание за недовложение | − |
| Расход | Частичная компенсация клиенту | − |
| Расход | Компенсация пересылки клиенту | − |
| Возврат прихода | Перевыставление услуг доставки | − |
| Возврат расхода | Удержание за недовложение | + |

### 2.2. Пример Ozon (эталон заполнения)

Удержания: 1 067,76 + 20 116,36 + 190 = **21 374,12 ₽**. Возврата прихода и возврата расхода нет, «Агентского отчёта» нет, задолженности перед Ozon нет.

Внести: **21 374,12 — Расход** и **21 374,12 — Приход**.

## 3. Wildberries

Инструкция Ozon Банка по WB: https://help-bank.ozon.ru/business/ausn/account-ausn-fns/settlement-wildberries

Логика та же (банк видит только выплату, удержания нужно добавить взаимозачётом из акта сверки WB). Конкретную таблицу типов строк WB **нужно прочитать в первоисточнике перед закрытием октября** — в этой документации она пока не зафиксирована.

## 4. Чего в правилах нет (важно не выдумывать)

- Нет правила «доход = сумма кредиторской задолженности из отчёта о реализации» — это трактовка прошлого бухгалтера, а не требование (см. `docs/04`).
- Нет правила «всё датировать последним числом месяца» — дата берётся из отчёта агента.
- Заём (получение и возврат тела) **не является** ни доходом, ни расходом; проценты по займу — расход.
