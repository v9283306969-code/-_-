## Ловушки парсинга
1. openpyxl не видит выписку Сбера (inlineStr, 1×1). Читать xl/worksheets/sheet1.xml через xml.etree; текстовые ячейки из m:is, индексы строк через sharedStrings.
2. Направление денег: Кредит (N) = поступление, Дебет (J) = списание. Не перепутать.
3. В выгрузке АУСН списания-неналоговая база (налоги, взносы, ЕНС) имеют пустые Приход и Расход — не принимать за поступления.
4. web_search / web_fetch могут падать без ключа (конфиг провайдера); Ozon через fetch не открывается (404) — читать через Chrome MCP.
5. Chrome MCP: take_snapshot по умолчанию verbose:false (обрезанное дерево) — использовать verbose:true; evaluate_script принимает поле function; type_text — только text в сфокусированный элемент; fill — uid+value; pageId нестабилен после рестарта браузера — всегда list_pages заново.
6. Сессии DSH: C:\Users\Proff\.dsh\sessions\...\session.v4.jsonl.zstd — много кадров zstd, декодировать по магическим байтам 28 B5 2F FD.
