# Алгоритм расчёта налога АУСН (объект «Доходы – Расходы», 20 %)

Налог ФНС считает автоматически по данным ЛК. Наша задача — правильно внести доходы и расходы,
а расчёт воспроизвести для проверки.

## 1. Налоговый период

Календарный месяц. Отчётность не сдаётся. Перенос убытка — только внутри режима, помесячно.

## 2. Формула (проверена по карточкам начислений ЛК АУСН)

1. База = Доходы − (Расходы + Убыток прошлых периодов), но не ниже 0.
2. Налог_20 = 20 % × База.
3. Налог_мин = 3 % × Доходы (минимальный налог).
4. Налог к уплате = max(Налог_20, Налог_мин).

Если применён минимальный налог: разница (Налог_мин − Налог_20) и остаток убытка переносятся
как «Убыток, переходящий на следующие налоговые периоды».

Порядок чтения строк в карточке «Расчет налога»: Доходы → Расходы (включая убыток прошлого периода)
→ Налоговая база → Ставка 20 % → флаг «Применен минимальный налог (3 % от суммы полученного дохода)»
→ Убыток полученный → Убыток переходящий.

## 4. Вывод, критичный для октября

В 5 месяцах из 8 налог = минимальные 3 % от доходов (расходы почти равны доходам, маржа тонкая).
Поэтому любая ошибка в доходе прямо двигает налог на 3 % от суммы ошибки,
а ошибка в расходах влияет только на выбор между 20 % и 3 %.

## 5. Что такое «доход» и «расход» для АУСН (кассовый метод)

- Доход — дата получения денег (банк) или взаимозачёта (удержание площадкой), не дата отчёта о реализации.
- Расход — только фактически оплаченные и из допустимого перечня: комиссии/услуги площадок, логистика, хранение, реклама, проценты по займам и т.п.
- Не доход: получение и возврат тела займа, перевод собственных средств, возврат ошибочного платежа.
- Не расход: погашение тела займа, переводы на личные нужды.
