# Порядок заполнения операций (для агента, однозначно)

Цель: в ЛК АУСН каждый месяц попадают правильные суммы доходов, возвратов прихода,
расходов и возвратов расхода.

## Шаг 0. Исходные данные месяца
1. Выписка банка за полный месяц (Сбер).
2. Акт сверки площадки за месяц (Ozon: Финансы → Документы → Акт сверки).
3. При наличии строки «Агентский отчёт» — Отчёт о перечислениях.
4. Договоры займов (Ozon Кредит, ВБ Финанс) — отделить проценты от тела.

## Шаг 1. Разметка банковских операций

| Событие в банке | Разметка АУСН |
|---|---|
| Поступление от площадки (Ozon/WB/ЯМ) | Приход |
| Внесение наличной выручки на счёт | Приход (если это выручка) |
| Получение займа / возврат ранее выданного займа | Неналоговая база |
| Перевод собственных средств / личные переводы | Неналоговая база |
| Оплата услуг, закупок, комиссий | Расход (если допустим по АУСН) |
| Погашение тела займа | Неналоговая база (не расход) |
| Уплата процентов по займу | Расход |

Правило направления в выписке Сбера: Кредит (столбец N) = поступление, Дебет (столбец J) = списание.

## Шаг 2. Взаимозачёт по акту сверки площадки

1. Каждой строке акта сверки присвоить тип по таблице (docs/01-Нормативная-база.md, раздел 2.1).
2. Посчитать четыре суммы: Расход, Возврат прихода, Возврат расхода, и по формуле:
   Приход = Расход + Возврат прихода − Возврат расхода.
3. В ЛК АУСН: Операции → Добавить → Взаимозачёт → вписать Приход / Возврат прихода / Расход / Возврат расхода.
4. Строку «Требование о переводе третьему лицу» внести дополнительным Приходом (автоматикой не передаётся).

## Шаг 3. Дата
Все операции относить к месяцу из отчёта агента (дата взаимозачёта площадки),
а не к последнему числу месяца и не к дате зачисления на счёт.

## Шаг 4. Контроль месяца
- Доход_месяца = Поступления от площадок (банк) + Приход взаимозачёта + внесённая наличная выручка.
- Расход_месяца = Расход взаимозачёта + допустимые банковские расходы.
- Сверить доход с карточкой «Расчет налога» ЛК АУСН после автоматического расчёта.
- Убедиться, что «Возврат прихода» попал в возврат прихода, а не в расход.

## Шаг 5. Фиксация
Результат записать в файл месяца и в рабочую таблицу с указанием источника каждого числа.

## Эталонный пример (Ozon)
Удержания 21 374,12 ₽, возвратов и «Агентского отчёта» нет, задолженности перед Ozon нет →
внести Расход 21 374,12 и Приход 21 374,12 (одна сумма, оба поля).
