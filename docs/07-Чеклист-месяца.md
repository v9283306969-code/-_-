# Чеклист закрытия месяца (повторять ежемесячно)

- [ ] Выписка банка за полный месяц (вкл. последний день).
- [ ] Акт сверки Ozon за месяц (+ Отчёт о перечислениях при «Агентском отчёте»).
- [ ] Акт сверки WB за месяц.
- [ ] Данные по Я.Маркет (если есть выручка).
- [ ] Договоры займов: «Требование о переводе третьему лицу» на тело/проценты.
- [ ] Разметить банк: поступления площадок и наличная выручка = Приход; займы/личные = неналоговая.
- [ ] Взаимозачёт по акту сверки: Приход = Расход + Возврат прихода − Возврат расхода.
- [ ] Внести взаимозачёт в ЛК АУСН (Операции → Добавить → Взаимозачёт).
- [ ] Внести «Требование о переводе третьему лицу» отдельным Приходом.
- [ ] Даты = месяц отчёта агента.
- [ ] Контроль: Доход = поступления + приход взаимозачёта + наличная выручка; Расход = расход взаимозачёта + допустимые банковские.
- [ ] Свериться с карточкой «Расчет налога» ЛК АУСН.
- [ ] Записать итоги в файл месяца и рабочую таблицу (с источником каждого числа).
