## 3. Методика разметки

**До сентября включительно:** банковские поступления маркетплейсов = «Неналоговая база»; доходы/расходы — по документам. Двусторонний Ozon «Выкуп товара у селлера» — техническая запись, не считается. Декомпенсация = «Возврат прихода».

**С ОКТЯБРЯ 2026 — официальная схема «взаимозачёт» (рекомендации ФНС / Ozon Bank):**
- Поступления от маркетплейсов = «Приход».
- Удержания = «Взаимозачёт» (Приход + Расход): Ozon — акт, перевыставление, «Звёздные», УПД-1, страховка; WB — строки 2.1–3 и 6–7 недельного отчёта.
- Займы: Приход = долг + проценты; Расход = только проценты.
- Возвраты: Приход + «Возврат прихода». Уведомления о выкупе WB не вносятся; только удержания из детального отчёта «По выкупам».
- Месяц операции = дата в отчёте маркетплейса.
- Переходные поступления (Ozon saldo 776 178,03 на 30.09; WB недели по 30.09) = «Неналоговая база» — за них уже отчитались.

**Месяц отчёта WB:** еженедельный отчёт → месяц даты в шапке (воскресенье; с 31.08 WB делит недели по границе месяца). Уведомление о выкупе → месяц его НЕДЕЛЬНОГО отчёта (дата «от» — понедельник), а не собственная дата.
